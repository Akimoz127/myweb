# AI Learning Streaming Platform (PWA)

A free AI learning streaming platform built by **Ahmed**, designed to organize and display educational AI videos in a clean, modern, neon-dark interface.  
The platform works as a **Progressive Web App (PWA)** and can be installed on desktop and mobile.

---

## 🚀 Features

### 🎬 Video Streaming
- Watch AI educational videos directly inside the platform.
- Clean and modern neon-dark UI.

### 📂 Categories System
- Videos are organized into categories:
  - AI Basics  
  - Machine Learning  
  - Deep Learning  
  - LLMs  
  - Prompt Engineering  
  - AI Ethics  
- Each category has its own page showing related videos.

### 🔥 Trending Page
- Automatically displays the most viewed videos.
- Sorted by `views` from `videos.json`.

### ⭐ Watch Later System
- Save videos to watch later.
- Stored in `localStorage`.
- Dedicated page: `watch-later.html`.

### 📱 PWA Support
- Installable on mobile and desktop.
- Works offline for cached pages.
- Includes `manifest.json` and `service-worker.js`.
